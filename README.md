# GTA V Fonts
A direct extraction of some fonts in Grand Theft Auto V, available to download as TTF files. Not all files have been extracted, but they will be added in future updates.

## How it was extracted
In _Grand Theft Auto V_, font files are stored inside Scaleform (`.gfx`) files. Using OpenIV, selections of those files, such as `font_lib_efig.gfx`, were opened in [JPEXS Flash Decompiler](https://github.com/jindrapetrik/jpexs-decompiler) (v.26.2.1), which has a native tool to extract and export such files as TrueType formats. This means all of Rockstar's modifications and customizations, like stroke weights, shapes, and extra glyphs, are preserved, and the font appears exactly as it does in-game.

## Installation
On any operating system that supports installing `.ttf` files, download the repo, extract the folder, and install any files you choose. Confirm they are installed by checking your installed fonts on Windows via the Control Panel, or in Font Book on macOS. You are now able to use them in any program that allows local user-installed typefaces.
