# GTA V Fonts
A direct extraction of some fonts in Grand Theft Auto V, available to download as TTF files. Not all files have been extracted, but there's a possibility more can be added once they are discovered.

## How it was extracted
In _Grand Theft Auto V_, font files are stored inside Scaleform (`.gfx`) files. Using OpenIV, selections of those files, such as `font_lib_efig.gfx`, were opened in [JPEXS Flash Decompiler](https://github.com/jindrapetrik/jpexs-decompiler) (v.26.2.1), which has a native tool to extract and export such files as TrueType formats. This means all of Rockstar's official modifications and customizations, like stroke weights, shapes, and extra glyphs, are preserved, and the font appears exactly as it does in-game.

## Installation
On any operating system that supports installing `.ttf` files, download the repo, extract the folder, and install any files you choose. Confirm they are installed by checking your installed fonts on Windows via the Control Panel, or in Font Book on macOS. You are now able to use them in any program that allows local user-installed typefaces.

The folders in this repo have names based on the original names of the files from which they were extracted from. Some might provide a good idea on where the fonts are commonly used. Otherwise, check out some noticable fonts you might be searching for. Otherwise, feel free to explore the other ones! Reference images coming soon in a future repo update.

1. `7_$Font2_ChaletLondonNineteenSixty.ttf` is used for main body in-game text.
2. `4_$FixedWidthNumbers_ChaletLondonNineteenSixtyNumb.ttf` has tabular numbers, modified off of Chalet London 1960. Used for timers and take numbers in status bars.
3. `3_$Font2_cond_ChaletComprime-CologneSixty.ttf` is used for condensed text, like usernames, larger titles, and longer strings in Interaction Menus.
4. `8_$RockstarTAG_RockstarTAG.ttf` is very similar to the condensed Chalet font, but is monospaced. Used in crew tags. Also contains some tag-shaped icon glyphs.
5. `7_$Font2_cond_MPTimer_GTAV Timer Fixed Cond.ttf` has tabular numbers, moddified off of Chalet Comprime. Used for the total time stat at the end of races, as well as other places.
6. `6_$Font5_SignPainter HouseScript.ttf` is used for road names and areas in the HUD, as well as job titles and yacht decals.
7. `1_$HandstyleHeist_Handstyle Heist.ttf` is used on heist planning boards.
8. `1_$Subtract_GTA Subtract.ttf` is most commonly used on the Cayo Perico Heist planning board, but also appears in some background windows on hacking interfaces in mini-games.
9. `1_$Font6_GTAV Casino Dots.ttf` is used for the matrix display texts on slot machines at the Diamond Casino.
10. `1_$Taxi_font_GTAVTaxiDigital.ttf` is used on the digital display in taxis.
11. `4_$gtaCash_PricedownGTA.ttf` is the **logotype** version of Rockstar's version of Pricedown. It does _not_ display in-game, and is soley used for the Grand Theft Auto logo.
12. `6_$gtaCash_PricedownGTAVInt.ttf` is the **in-game** version of Rockstar's version of Pricedown. It _does_ display in-game, used only for the most prominent text, as well as for the money and ammo counter.
13. `1_RL_Arial.ttf` contains a very small amount of characters, presumably used exclusively in labels for X-Box controller buttons.
14. `5_$GTAVLeaderboard_GTAV LeaderBoard.ttf` contains random icon glyphs for leaderboards.
